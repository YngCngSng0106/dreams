# 梦境分享 App 前端

基于 UniApp + Vue3 + Vite 的跨平台前端应用。

## 技术栈

- **框架**: UniApp (Vue3 + Vite)
- **UI风格**: 紫蓝色渐变主题 (小而美)
- **网络请求**: 封装的 request.js
- **日期处理**: dayjs

## 目录结构

```
src/
├── pages/            # 主包页面 (5个Tab)
│   ├── explore/      # 探索 (首页信息流)
│   ├── dream-record/ # 记录梦境
│   ├── discussion/   # 讨论社区
│   ├── message/      # 消息通知
│   └── mine/         # 我的 (个人主页)
├── pages/auth/       # 认证 (分包)
│   ├── login/        # 登录
│   └── register/     # 注册
├── pages/detail/     # 详情页 (分包)
│   ├── dream-detail  # 梦境详情
│   ├── dream-edit    # 编辑梦境
│   ├── discussion-detail  # 讨论组详情
│   ├── profile       # 个人主页
│   ├── search        # 搜索
│   ├── settings      # 设置
│   └── notifications # 通知列表
├── utils/            # 工具类
│   ├── request.js    # 网络请求封装 + 上传
│   ├── api.js        # 所有API接口
│   └── auth.js       # 登录状态管理
├── static/           # 静态资源
├── App.vue           # 根组件 (全局样式)
├── main.js           # 入口
├── pages.json        # 路由配置 + TabBar
└── uni.scss          # 全局样式变量
```

## UI设计

- **主题色**: #6C5CE7 紫色渐变
- **辅助色**: #A29BFE 浅紫, #00CEC9 青色, #FD79A8 粉色
- **卡片**: 24rpx圆角 + 柔和阴影
- **导航栏**: 渐变背景 + 自定义样式
- **TabBar**: 5个Tab (探索/记录/讨论/消息/我的)

## 页面列表 (共14个)

**主包 (5个Tab页)**:
1. explore — 探索页 (信息流 + 分类筛选 + 点赞)
2. dream-record — 记录梦境 (表单 + 分类选择 + 图片上传)
3. discussion — 讨论社区 (Tab切换: 全部/我的/推荐)
4. message — 消息通知 (通知列表 + 未读标记)
5. mine — 我的 (个人信息 + 统计 + 菜单)

**分包 - 认证 (2页)**:
6. login — 登录 (渐变背景 + 表单)
7. register — 注册 (带确认密码)

**分包 - 详情 (7页)**:
8. dream-detail — 梦境详情 (图片 + 描述 + 信息 + 相似推荐 + 点赞)
9. dream-edit — 编辑梦境 (表单 + 删除)
10. discussion-detail — 讨论组详情 (加入/退出 + 评论列表)
11. profile — 个人主页 (信息 + 关注/取关 + 梦境列表 + 统计)
12. search — 搜索 (关键词 + 分类Tab + 热门标签)
13. settings — 设置 (个人信息 + 推送/匿名开关 + 改密 + 注销)
14. notifications — 通知列表 (全部已读 + 下拉刷新)

## 开发

### 1. 安装依赖

```bash
cd frontend
npm install
```

### 2. 配置后端地址

修改 `src/utils/request.js` 第一行:

```js
const BASE_URL = 'http://你的后端地址:8080';
```

### 3. 运行

使用 HBuilderX 打开项目，选择运行到 H5/小程序/APP。

## 功能清单

- 登录/注册 (JWT认证)
- 梦境记录 (分类+日期+地点+关键词+清晰度+描述+重复标记+图片)
- 梦境信息流 (全部分类筛选+上拉加载+下拉刷新)
- 梦境详情 (完整信息+图片预览+相似梦境推荐)
- 点赞/取消点赞
- 编辑/删除梦境
- 讨论组 (创建+列表+详情+加入/退出+邀请+推荐)
- 评论/回复 (支持嵌套回复+评论点赞)
- 关注/取关
- 通知系统 (实时推送+列表+已读标记)
- 搜索 (梦境/用户/讨论组综合搜索+热门标签)
- 个人主页 (统计+梦境列表+关注关系)
- 用户设置 (推送开关+匿名模式+修改密码+注销账号)
- 图片上传 (最多3张+预览+删除)
